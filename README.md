# PhishGuard AI

An AI/ML-based phishing URL detection system designed to analyse URL characteristics and identify potentially malicious links.

## Objective
To build a machine learning model that classifies URLs as potentially legitimate or phishing based on extracted URL features.

## Planned Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- FastAPI
- Streamlit

## Planned Features
- URL feature extraction
- Phishing URL classification
- Machine learning model comparison
- Model evaluation using accuracy, precision, recall and F1-score
- Interactive web interface

## Project Status
Currently under development.

## Disclaimer
This project is an educational prototype. Its predictions are not a guarantee that a URL is safe or malicious.
